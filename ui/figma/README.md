# Figma 组件（导入用）

## 文件

| 文件 | 用途 |
|---|---|
| `components.svg` | 组件总览，**导入 Figma 后是矢量图层**，可直接改色改字 |
| `components_preview.png` | 预览图，看整体效果用 |

## 导入步骤

1. Figma 里新建文件，画板 360 × 780（和文档的基准屏一致）
2. `File → Place image` 选 `components.svg`（或直接拖进来）
3. 导入后是**一个组**，右键 `Ungroup` 两到三次，直到每个矩形和文字都能单独选中
4. 把常用组件右键 `Create component`（顶栏、订单卡三态、按钮两态、棋盘格、仓库格、信息条）

## 注意

- 总览图是 **1dp = 1px**，导入后不要缩放，直接按 1x 用
- 字体用的是 `Noto Sans SC`，Figma 里如果没有会自动替换，记得统一改回
- 颜色色值写在图下方的「颜色令牌」区，逐个建 `Color style`
- 尺寸标注直接写在每个组件上方（如 `订单卡 180×96`），照着建 Frame 即可

## 不需要做的

**不需要再画 9 屏像素级视觉稿。** 项目要直接做成 app，开发依据是：

- `docs/06` 九屏线框（结构、尺寸、交互）
- `docs/07` 开发规格（主题令牌、组件映射、手势、验收清单）
- 本目录的 `components.svg`（精确到 dp 的组件外观）

再画一遍等于同一件事做两遍。

## 可选的

只做 **2 屏成品效果图**（主界面 + 建造界面），用真实素材合成，用于答辩和项目文档展示。
它不承担开发依据的作用。
