## 怎么用（三步）

1. 打开 `docs/data/prompts.txt`
2. 找到编号，复制标题**下面那一整段**
3. 粘进 Gemini，发送

不用再加风格段，不用再加负面词，不用改标点。**一段就是一条完整指令。**

## 一条提示词长什么样

`prompts.txt` 里每块是两行：

```
1. ic_wood_1 木屑
温暖手绘风2D手游图标，……纯白背景，…… 画面内容：一小撮浅色卷曲的木屑，浅松木色。 避免：写实、3D渲染、……
```

- 第 1 行是**编号 + 文件名 + 中文名**，给你自己看的，不要发。
- 第 2 行才是**要发的内容**，整段复制。

它其实就是三段拼起来的：

```
[风格段] + 画面内容：xxx。 + [负面词]
```

## 出图顺序

| 步 | 复制哪几条 | 说明 |
|---|---|---|
| 1 | 第 3 条（`ic_wood_3` 木板） | 只发这一条，看风格对不对 |
| 2 | 满意后发一句 | "很好，接下来所有图都保持和这张完全一样的画风、描边、配色和阴影" |
| 3 | 每次发下一条时 | 把第 1 张图也上传，一起发 |
| 4 | 同一条链的 6 级 | 在同一个对话里连着发，风格最稳 |

## 拿到图之后

```
1024×1024 → 抠掉白底 → 加 4px 深棕描边 → 缩到 288×288 → 命名 ic_wood_3.png
```

房间图不一样：`1152×2048 → 缩到 1080×1920 → 存 WebP`，不用抠图（它本来就有背景）。

## 三个常见问题

| 现象 | 怎么办 |
|---|---|
| 图里出现了文字、边框、木牌上的字 | 重发同一条，末尾补一句"不要任何文字，牌子留空" |
| 一批图风格飘了 | 回到第 1 张锚点图那个对话里继续发，别开新对话 |
| 想要透明背景 | Gemini 给不了透明图，只能白底，后期自己抠 |
