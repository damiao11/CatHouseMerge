# 06 · UI-UX 设计规范

> 评分重点是 UI，所以这一章要写成"可以直接照着做"的规范，而不是感觉描述。
> 原则：**温暖、手账、木质、不花哨**。所有界面都要像同一本笔记本里的纸页。

## 6.1 三个关键词

| 关键词 | 具体表现 | 反例 |
|---|---|---|
| **纸感** | 米白背景、纸纹、撕边、印章、胶带 | 纯白 + 蓝色科技感 |
| **木色** | 暖木色系为主，深棕描边 | 高饱和霓虹 |
| **留白** | 信息不塞满，一行只讲一件事 | 满屏数字和红点 |

## 6.2 色彩系统

| 角色 | 色值 | 用在哪 |
|---|---|---|
| 背景·米白 | `#FBF6EC` | 全局背景 |
| 纸卡 | `#FFFDF8` | 卡片、对话框 |
| 主色·暖木 | `#D9A15B` | 顶栏、进度条、选中态 |
| 深木 | `#A9703C` | 描边、阴影、次级按钮 |
| 强调·陶土橙 | `#E2703A` | 主按钮、金币、关键 CTA |
| 植物绿 | `#7FA05A` | 成功、花园、正能量 |
| 深绿 | `#55703C` | 绿色文字（保证对比度） |
| 文字主 | `#3E3226` | 标题、正文 |
| 文字次 | `#8A7A66` | 说明、禁用 |
| 分割线 | `#E8DCC8` | 1dp 分割 |
| 成功 | `#6FA36B` | 完成勾 |
| 警告 | `#E0A33E` | 能量不足 |
| 禁止 | `#C0564A` | 不可放置 |

**使用比例**：米白 60% / 木色 25% / 橙 10% / 绿 5%。橙色只用在"现在该点的地方"，一屏不超过 2 处。

## 6.3 字体

| 层级 | 字体 | 字号 | 字重 | 行高 |
|---|---|---|---|---|
| 大标题（天数印章） | 思源宋体 | 28sp | Bold | 36 |
| 页面标题 | 思源宋体 | 22sp | SemiBold | 30 |
| 卡片标题 / 订单 | 思源黑体 | 18sp | Medium | 26 |
| 正文 / 对话 | 思源黑体 | 16sp | Regular | 28 |
| 辅助说明 | 思源黑体 | 14sp | Regular | 20 |
| 角标 / 数字 | 思源黑体 | 12sp | Medium | 16 |

- 数字用**等宽**（`FontFeatureSettings("tnum")`），金币跳动时不抖。
- 不用系统默认字体（会显得没设计过），思源系列免费可商用。
- 对话文本**最多 2 行**，超出必须拆句。

## 6.4 布局基础

| 项 | 值 |
|---|---|
| 基准屏 | 360 × 780 dp（1080×2340 手机） |
| 栅格 | 4dp 基准，8dp 为主间距 |
| 页面边距 | 16dp |
| 卡片圆角 | 16dp；弹层 24dp；按钮 999dp（胶囊） |
| 卡片阴影 | `0 2dp 8dp rgba(62,50,38,0.08)` + `0 1dp 2dp rgba(62,50,38,0.06)` |
| 描边 | 1dp `#E8DCC8`；物品图标 2dp `rgba(62,50,38,0.2)` |
| 触控区 | 最小 48 × 48dp |
| 安全区 | 底部预留 24dp 手势条 |

## 6.5 物品图标规范

| 项 | 规范 |
|---|---|
| 原生画布 | 1024 × 1024，内容占 70–80%，四周留白 |
| 导出尺寸 | 288 × 288 PNG-24（@3x 下显示 96dp 的画布） |
| 显示尺寸 | 棋盘格内 40dp；订单需求格 52dp |
| 描边 | 统一中等粗细深棕 `#3E3226`，由出图时直接画进图里，**不在代码里加描边** |
| 投影 | 图内自带一层柔和接触阴影，代码不再加阴影 |
| 等级表达 | **不画角标**。靠外形、材质、颜色区分；等级只在底部信息条里用文字显示 |
| 链标识 | **不做底托、不做形状标记**——成品是“单物件 + 纯白背景”，靠物品本身识别 |
| 一致性 | 39 个图标 + 35 级生成器放一起必须像一套：同一光源、同一描边、微俯视四分之三 |

> **不要用 emoji 当图标**。答辩时会显得没做完。

> 布局参考《肥鹅美食街》：**左下角是建造**、**底部中间常驻物品信息条**、右下角是仓库。
> 物品图标上**不画等级角标**，等级和说明只在信息条里出现——点一下物品，信息条就切到它。
> 顶栏从左到右：**天 / 体力（当前值 + 下一点倒计时）/ 金币 / 图鉴 / 设置**。
> **体力只显示当前值**，上限 150 不常驻——点体力图标才弹浮层显示 `62 / 150`、下一点倒计时和"5 小时回满"。

### 6.7.1 订单卡结构（参考图的细节）

| 区块 | 内容 | 说明 |
|---|---|---|
| 头像 | 猫头像 44dp，圆形 | "猫的请求"卡在头像右下加一枚**爪印角标** |
| 需求格 | **固定 2 格**，每格 52dp | 物品图标 + 右下角 `现有/需要`（如 `4/6`）；凑齐变绿。订单最多 2 种物品，所以格子永远够 |
| 奖励行 | 金币图标 + 数字 | 剧情单在金币后加一个爪印图标，表示"解锁一段对话" |
| 卡片 | **180 × 96 dp** | 木框 + 米白底 + 16dp 圆角；普通 / 可交付（绿边+呼吸）/ 已交付（打勾翻面后淡出） |

**和参考图唯一的故意分歧：不做"拖一件交一件"。**

- 参考图的 `0/1` 是逐件提交；我们的订单一次要 2–6 件，逐件拖会非常累。
- 所以 `n/m` 表示**棋盘上当前拥有 / 需要**，实时更新；凑齐后**点一下卡片**一次性交付。
- 不足时点卡片：抖动 + "还差 2 个木板"，不弹窗。

**视觉层级**（从上到下要有明显区分）：

1. 棋盘（主角，最亮、最居中）
2. 订单条（次亮，但不能抢棋盘）
3. 棋盘上的生成器（有"可以点"的呼吸感）
4. 顶栏 / 底栏（压暗，退到后面）

### 6.7.2 建造界面（第 3 屏，独立整屏）

> 从主界面底栏「建造」进入。**不是弹层、不是抽屉**，是整屏切换（自下而上滑入，240ms）。
> 背景就是房间图（9:16 全屏 cover），UI 浮在上面，左右不留白。

**线框**

```
┌───────────────────────────────────────┐
│ ←  门廊                      🪙 248   │ ← 顶栏 56dp，背后压一层 20% 深棕
├───────────────────────────────────────┤
│                                       │
│                                       │
│         房间图 9:16 · cover 铺满        │
│         （主体在垂直中间 60%）          │
│                                       │
│                                       │
├───────────────────────────────────────┤
│  第 2 / 3 步                  ●●○     │ ← 面板 232dp，米白 96%
│                                       │
│  [🔨]  补好门廊栏杆                     │ ← 当前步骤：图标 44 + 名称 + 花费
│        130 🪙                          │
│                                       │
│  ┌─────────────────────────────────┐  │
│  │       修好这一步 · 130 🪙        │  │ ← 主按钮 56dp 胶囊
│  └─────────────────────────────────┘  │
│                                       │ ← 预留 24dp 手势条
└───────────────────────────────────────┘
```

**三段高度**

| 区 | 高度 | 说明 |
|---|---|---|
| 顶栏 | 56dp | 返回、房间名（左对齐）、金币（右对齐）；半透明深棕压暗，避免和房间图抢 |
| 房间图 | 剩余（约 492dp） | `ContentScale.Crop`，不裁圆角、不加遮罩 |
| 底部面板 | 232dp | 米白 `#FBF6EC` 96%，顶部 16dp 圆角，含手势条留白 |

**三种步骤状态**

| 状态 | 圆点 | 步骤行 | 按钮 |
|---|---|---|---|
| 已完成 | 实心 | 打勾 + 40% 灰 | —— |
| **当前** | 描边 + 呼吸 | 正常，图标彩色 | 可用 |
| 未开始 | 空心 | 40% 透明 | 不可用 |
| 金币不足 | 不变 | 不变 | 变灰 + 文案「还差 40 🪙」 |

> 金币不足时点按钮：只抖动 200ms，**不弹窗、不跳转**。跳转会打断玩家看房间。

**建造流程（一次一步）**

1. 点主按钮 → 金币数字滚动扣除（300ms）
2. 播放**建造揭幕**：房间图从左到右擦除，露出修好后的图（900ms）
3. 步骤圆点前进一位，步骤行打勾
4. 若这是第 3 步：面板换成「这间修好了」，按钮变「返回主界面」
5. 返回时主界面「建造」按钮上的小红点消失

**规则约束**

| 项 | 规定 |
|---|---|
| 体力 | 建造**不消耗体力** |
| 订单 | 建造期间订单暂停刷新，不消失、不超时 |
| 金币不足 | 不阻止进入，只是按钮不可用（让玩家看见目标） |
| 中途退出 | 已完成的步骤不回退，下次进来继续下一步 |

**用到的美术资源**

| 资源 | 文件 | 何时显示 |
|---|---|---|
| 房间图 · 前 | `rooms/room_{room}_before.png` | 第 1–3 步未完成时 |
| 房间图 · 后 | `rooms/room_{room}_after.png` | 第 3 步完成后 |

擦除动画由代码做遮罩，**不需要额外图片**。

## 6.8 合成板交互细节

| 操作 | 反馈 |
|---|---|
| 按下物品 | 立即放大 1.12、上浮 2dp、投影加深（不等长按） |
| 点击物品/生成器 | 选中：格子描边高亮；底部信息条切到它（名称 + 等级 + 一句话） |
| 再点一次 / 点空白 | 取消选中，信息条回到默认提示 |
| 点击 vs 拖拽 | 位移 < 8dp 算点击，≥ 8dp 进入拖拽 |
| 拖起物品 | 棋盘上所有**同级同链**的物品描边发光——不用靠眼睛分等级 |
| 拖动 | 物品跟手，原位留 20% 透明剪影 |
| 点订单卡（已凑齐） | 一次性交付：物品扣除 → 金币飞入 → 卡片翻面打勾 → 淡出 |
| 点订单卡（未凑齐） | 卡片抖动 + "还差 2 个木板"，不弹窗 |
| 拖订单卡 | **不可拖**；订单行只响应横向滑动，卡片不参与拾取 |
| 悬停到合法格 | 格子描边高亮 `#D9A15B`，3dp |
| 悬停到可合成目标 | 目标物品呼吸放大 + 金色光晕 |
| 悬停到非法格 | 格子变红 30%，拖回时弹回原位 200ms |
| 松手合成 | 两物品向内收拢 → 白光一闪 → 新物品 1.15 倍弹回 1.0 |
| 点生成器 | 物品从生成器口弹出，抛物线 300ms，落到相邻空格 |
| 拖生成器 | 和拖物品一样：跟手、原位留剪影、可放到任意空格 |
| 拖到仓库按钮 | 按钮放大 1.1、图标变实心，松手即收纳 |
| 从气泡拖出 | 气泡整块收起（宽度收为 0），后面的卡片左移；生成器跟手，落到格子才生效，放不下就弹回 |
| 从仓库拖出 | 仓库面板半透明浮起，拖回棋盘空格 |
| 仓库满 | 按钮抖动 + "仓库满了，先卖掉点" |
| 拖生成器靠近 | 同级生成器互相吸附、发光，中间浮出"合成" |
| 松手合生成器 | 两个合成一个，外形换一档，配"咔"声 + 短震动 |
| 板面满 | 生成器抖动 + 提示条"先卖掉点东西吧"，不弹窗 |

**手感三条铁律**：

1. 任何操作 **0.1 秒内必须有反馈**（哪怕只是按下态）。
2. 拖拽判定用**中心点**，不用手指位置，避免"明明放上去了却没合"。
3. 合成成功必须**有声音 + 有粒子 + 有震动**，三重反馈。

## 6.11 引导（前 90 秒）

见 [03 文档 3.8](03-天数关卡与难度曲线.md)。UI 上只做三件事：

1. **手指图标**：一个半透明手指，带呼吸动画，指向该点的位置。
2. **高亮遮罩**：其余区域压暗 40%，只留目标。
3. **不打断**：引导期间玩家仍可自由操作，做对了就消失，不做就一直提示。

> 不要做"必须点这里才能继续"的强制引导，会让人烦躁。

## 6.12 可用性与无障碍

| 项 | 要求 |
|---|---|
| 触控 | 所有可点区域 ≥ 48dp；棋盘格 44dp 是唯一例外，靠拖拽补偿（拖拽不要求精确点击） |
| 对比度 | 正文 ≥ 4.5:1，大标题 ≥ 3:1 |
| 色盲 | 等级靠**外形 + 尺寸**区分，点击后信息条给出文字等级；拖起时同级高亮 |
| 字号 | 跟随系统字体缩放（`sp`，不用 `dp`） |
| 单手 | 主要操作区在屏幕下半 2/3 |
| 静音 | 音效可单独关闭，不影响 BGM |
| 动画 | 提供"减少动态效果"开关（系统设置联动） |
