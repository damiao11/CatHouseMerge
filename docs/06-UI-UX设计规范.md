# 06 · UI-UX 设计规范

> 文档 v0.3 · 2026-11-17 · 对应应用 0.3.0 / 3（待验收、未发布）。
> 当前方案以 [DESIGN.md](../DESIGN.md)、UI-v1 与原生 Compose 为依据；旧木质视觉被替代，历史验证记录不覆盖。
> 本章保留其他页面的设计目标，但线框、粒子、逐字对话、独立 BGM/SFX 等描述并非全部已实现。已实现范围及实测证据见 [本轮记录](design/implementation-2026-11-17.md)。

## 6.1 三个关键词

| 关键词 | 具体表现 | 避免 |
|---|---|---|
| 明快 | 黄绿色底、蜂蜜黄操作 | 厚重深色顶栏 |
| 柔和 | 奶油面板、焦糖描边、浅蓝棋盘 | 重木纹和强阴影 |
| 清楚 | 用图标与数值表达资源，绿色按钮表达可交付 | 重复标签、空格提示、常驻物品等级 |

## 6.3 字体

现有随包 Noto Sans SC 用于游戏 UI，`TitleFont` 与 `BodyFont` 同源；封面专用字体保持已有实现及授权说明。不新增字体下载或资源替换。

| 层级 | 常规字号 | 说明 |
|---|---|---|
| 页面标题 | 22sp | 半粗 |
| 卡片标题 / 正文 | 14–16sp | 随系统字号 |
| 物品介绍正文 | 约 13sp | 比旧版放大，避免上下空白过多 |
| 订单名称 / 数量 | 11sp / 10sp | 紧凑需求区，图标辅助识别 |
| 订单交付按钮 | 12sp | 粗体 |
| 日期 / 资源数字 | 按槽位自适应 | 日期深棕，大字号不挤出边界 |

长物品名按可用宽度调整标题字号，完整呈现名称、等级，不侵占出售区。对话长度仍以易读为目标，不能将旧稿行数约束冒充全部实测完成。

## 6.4 布局基础

- 竖屏，4dp 基准；实际随窗口、系统字号与系统安全区适配，不把网页像素写死到原生。
- 奶油面板通常 16dp 圆角、焦糖边缘；`GamePanel` 外边左右／上 2dp、下 4dp，形成轻微立体感。
- 棋盘始终 7×9，格子正方形；不强制固定 44dp。订单、说明与操作保持稳定槽位，状态切换不得改变棋盘位置或尺寸。
- 订单卡常规 272×104dp；字号大于 1.2 倍时 296×104dp。下方详情正文增大，减少无效留白。
- 触控与内容图标尺寸分开考虑；48dp 是无障碍验收目标，不将紧凑组件一律宣称已达标。以设备测试、语义和实际命中区域验证。

## 6.5 物品图标规范

| 项 | 规范 |
|---|---|
| 原生画布 | 1024 × 1024，内容占 70–80%，四周留白 |
| 导出尺寸 | 288 × 288 PNG-24（@3x 下显示 96dp 的画布） |
| 显示尺寸 | 棋盘格内 40dp；订单需求格 52dp |
| 描边 | 统一中等粗细深棕 `#3E3226`，由出图时直接画进图里，**不在代码里加描边** |
| 投影 | 图内自带一层柔和接触阴影，代码不再加阴影 |
| 等级表达 | **不画角标**。靠外形、材质、颜色区分；等级只在底部信息条里用文字显示 |
| 链标识 | **不做底托、不做形状标记**——源图是“单物件 + 纯白背景”，原生接入使用已去白底的透明 PNG，靠物品本身识别 |
| 一致性 | 39 个图标 + 35 级生成器放一起必须像一套：同一光源、同一描边、微俯视四分之三 |

> **不要用 emoji 当图标**。答辩时会显得没做完。

### 6.7.1 订单卡结构

| 区块 | 当前规范 |
|---|---|
| 面板 | 奶油底、焦糖描边，无橙色底栏；常规 272×104dp，大字号宽 296dp |
| 左侧 | 猫、需求图、名称和数量整体适当右移，避免留白太多 |
| 需求 | 来自实际订单的需求行，实时显示棋盘当前拥有 / 需要；凑齐显示正常方向绿色对号 |
| 右上 | 交付按钮；满足需求仅变绿色，不显示「材料已备齐」 |
| 右下 | 金币图标 + 数额，无「金币奖励」等标签 |

只有点「交付」按钮才执行一次性交付；不做拖一件交一件，也不通过点击整张卡误交付。未满足时保留真实缺少反馈。金币、需求与奖励来自引擎，不从原型示例拷贝数值。

### 6.7.2 修缮界面（独立整屏）

- 场景与奶油任务面板分开取景，保留轻量返回、金币及房间标签；不叠整条深灰遮罩。
- 标签不含「插画」二字；任务面板包含真实进度、已完成／当前／未来任务与当前费用按钮。
- 每一步扣实际金币、不消耗体力，进度持久化。金币不足提示实际缺额并提供返回合成途径，不增加规则限制。
- 只使用每间房已有 before/after 两张场景。整间修好前保持 before；整间修好后切 after，不伪造每个任务的中间态。
- 修好后仅底部保留一个对比按钮：看 after 时「重新看看修缮前」，看 before 时「重新看看修缮后」。不留右上角重复「看看修好后」。
- 建造成功提示中部略偏上，停留 1200ms 后淡出。

以下其他页面线框保留为功能设计目标，主题继承本版；没有单独重设计或验证的细节不视作本轮新增实现。

| 元素 | 规格 |
|---|---|
| 遮罩 | 当前房间图压暗 60%，不模糊 |
| 对话框 | 左右 16dp、底 24dp（避手势条）；高 168–200dp 自适应；圆角 24dp；底 `CardPaper`；边框使用 `DarkWood`；投影 `0 4 12 rgba(62,50,38,.18)` |

| 退场 | 200ms 淡出，不做位移 |

## 6.8 合成板交互细节

| 操作 | 反馈 |
|---|---|
| 按下物品 | 立即放大 1.12、上浮 2dp、投影加深（不等长按） |
| 点击物品/生成器 | 选中：格子描边高亮；底部信息条切到它（名称 + 等级 + 一句话） |
| 再点一次 / 点空白 | 取消选中，信息条完全留空，保留固定尺寸 |
| 点击 vs 拖拽 | 位移 < 8dp 算点击，≥ 8dp 进入拖拽 |
| 拖起物品 | 棋盘上所有**同级同链**的物品描边发光——不用靠眼睛分等级 |
| 拖动 | 物品跟手，原位留 20% 透明剪影 |
| 点交付按钮（已凑齐） | 一次性交付：引擎扣物品、加金币，更新订单状态，显示短成功提示；额外飞币/翻面为待验收动效目标 |
| 点交付按钮（未凑齐） | 卡片抖动 + "还差 2 个木板"，不弹窗 |
| 拖订单卡 | **不可拖**；订单行只响应横向滑动，卡片不参与拾取 |
| 悬停到合法格 | 格子描边高亮 `SelectionYellow`，3dp |
| 悬停到可合成目标 | 目标物品呼吸放大 + 金色光晕 |
| 悬停到非法格 | 格子变红 30%，拖回时弹回原位 200ms |
| 松手合成 | 两物品向内收拢 → 白光一闪 → 新物品 1.15 倍弹回 1.0 |
| 点生成器 | 物品从生成器口弹出，抛物线 300ms，落到相邻空格 |
| 拖生成器 | 和拖物品一样：跟手、原位留剪影、可放到任意空格 |
| 拖到仓库按钮 | 按钮放大 1.1、图标变实心，松手即收纳 |
| 从气泡拖出 | 气泡整块收起（宽度收为 0），后面的卡片左移；生成器跟手，落到格子才生效，放不下就弹回 |
| 从仓库拖出 | 仓库面板半透明浮起，拖回棋盘空格 |
| 仓库满 | 按钮抖动 + "仓库满了，先卖掉点" |
| 拖生成器靠近 | 同级生成器互相吸附、发光，中间浮出"合成" |
| 松手合生成器 | 两个合成一个，外形换一档，配"咔"声 + 短震动 |
| 板面满 | 生成器抖动 + 提示条"先卖掉点东西吧"，不弹窗 |

**手感三条铁律**：

1. 任何操作 **0.1 秒内必须有反馈**（哪怕只是按下态）。
2. 拖拽判定用**中心点**，不用手指位置，避免"明明放上去了却没合"。
3. 合成成功必须**有声音 + 有粒子 + 有震动**，三重反馈。

## 6.9 动效清单

**本版已实现的消息反馈**：交付／建造成功停留 1200ms，其他提示停留 2400ms，位于画面中部略偏上；淡入 100ms、淡出 220ms。减少动态效果时淡入淡出设为 0。停留时长与动画时长分别计算。

以下为原有动效目标清单，不代表本轮全部实现；不得据此宣称逐步揭幕、翻面飞币、粒子或逐字对话已完成。

| 元素 | 触发 | 时长 | 曲线 |
|---|---|---|---|
| 按钮按下 | tap | 120ms | ease-out |
| 物品拾起 | drag start | 120ms | spring(0.9) |
| 合成 | merge | 260ms | overshoot 1.15 |
| 生成器升级 | gen merge | 400ms | 缩放 + 换图 + 光晕扩散 |
| 气泡收起 | bubble empty | 300ms | 宽度收到 0 + 淡出，后续卡片左移 |
| 信息条切换 | 点选物品 | 120ms | 内容淡入，**高度不变**（防止棋盘跳动） |
| 订单完成 | submit | 600ms | 卡片翻面 + 金币抛物 |
| 金币飞入 | reward | 500ms | ease-in-out |
| 建造揭幕 | build | 900ms | 从左到右擦除 + 前后对比 |
| 天数切换 | day end | 1200ms | 黑场 + 印章落下 |
| 猫出场 | dialogue | 400ms | 从下淡入 + 轻微弹跳 |
| 对话打字 | text | 30 字/秒 | linear |
| 板面满提示 | blocked | 300ms | 左右抖动 3 次 |

> **动效不要超过 1 秒**（除天数切换）。移动端玩家没有耐心看 2 秒的转场。

## 6.10 声音

当前正式音频仍为本地合成提示音，BGM 与独立混音控制属于后续目标；网页模拟设置不算完成。

> 完整的 5 段 BGM + 44 条 SFX 清单、混音规范、触发对照和实现建议，见 **[15 音效与 BGM](15-音效与BGM.md)**。
> 这里只留三条硬规则：**合成声不超过 0.25 秒**、**同一音效 60ms 内不重复**、**BGM 与 SFX 必须能分开静音**。

## 6.11 引导（前 90 秒）

见 [03 文档 3.8](03-天数关卡与难度曲线.md)。UI 上只做三件事：

1. **手指图标**：一个半透明手指，带呼吸动画，指向该点的位置。
2. **高亮遮罩**：其余区域压暗 40%，只留目标。
3. **不打断**：引导期间玩家仍可自由操作，做对了就消失，不做就一直提示。

> 不要做"必须点这里才能继续"的强制引导，会让人烦躁。

## 6.12 可用性与无障碍

| 项 | 要求 |
|---|---|
| 触控 | 所有可点区域 ≥ 48dp；棋盘格 44dp 是唯一例外，靠拖拽补偿（拖拽不要求精确点击） |
| 对比度 | 正文 ≥ 4.5:1，大标题 ≥ 3:1 |
| 色盲 | 等级靠**外形 + 尺寸**区分，点击后信息条给出文字等级；拖起时同级高亮 |
| 字号 | 跟随系统字体缩放（`sp`，不用 `dp`） |
| 单手 | 主要操作区在屏幕下半 2/3 |
| 静音 | 设计目标为音效与 BGM 分开；当前本地提示音，正式 BGM 待接入 |
| 动画 | 提供"减少动态效果"开关（系统设置联动） |

## 6.13 异常与状态

| 状态 | 表现 |
|---|---|
| 空棋盘 | 生成器轻微呼吸 + 箭头提示，不弹窗 |
| 未选中物品 / 点击空格 | 信息条完全留空，槽位不缩小，不显示文字提示 |

| 气泡空了 | 自动缩回消失，不弹提示 |
| 气泡里的工具拖不动 | 棋盘没空格 → 抖动 + "先腾个位置" |

| 点体力图标 | 浮层：`62 / 150`、下一点倒计时、`5 小时回满` |
| 倒计时 < 10 秒 | 数字变琥珀色；回满瞬间闪一下 +1 的飘字 |
| 金币不足 | 建造按钮变灰 + 显示"还差 120"，点击跳到订单条 |
| 断线/离线回来 | "你离开了 3 小时，能量已恢复" |
| 存档失败 | 顶部黄色条，不打断游戏 |
| 首次进入 | 直接开始 D1，不做登录/开场动画 |
