# 12 · AI 出图指南（Gemini 网页版 · 中文提示词）

> 目标：用 Gemini 批量出**风格统一**的 2D 游戏素材。
> 清单和数量在 [11 美术清单](11-美术清单.md)，色板和字号在 [06 UI 规范](06-UI-UX设计规范.md)，这里只讲**怎么把要求喂给 AI**。

## 0. 开始前必须知道的四件事

1. **Gemini 出不了透明背景**。它给的是白底图，需要你自己抠（remove.bg / PS / `rembg`）。所以提示词里一定写"纯白背景、阴影别落到背景上"。
2. **一次只出一个对象**。让它"画六个物品"必然糊，还会把六个挤在一起。要 39 个就生成 39 次。
3. **风格靠参考图锁**，不靠形容词。先生成 1 张"风格锚点"（建议用"木板"），之后每次都在同一个对话里上传它，说"保持这张图完全一样的画风"。
4. **UI 面板不要用 AI 画**。9-slice 圆角、描边、内阴影，AI 做不准，后面切图会崩。UI 用 Figma 或代码画。

## 1. 风格锁定段（每张图都粘这段）

```
温暖手绘风 2D 手游图标，扁平矢量风格，带轻微纸纹质感；
每个形状都有统一的中等粗细深棕色描边（#3E3226）；
圆角；略微俯视的四分之三视角；
暖色低饱和配色：米白 #FBF6EC、蜜木 #D9A15B、深木 #A9703C、陶土橙 #E2703A、叶绿 #7FA05A；
纯色块，没有渐变、没有高光、没有发光；
只画一个物体，居中，四周留足空白；
纯白色背景；只有物体正下方有一层柔和的接触阴影；
不要文字、不要数字、不要水印、不要边框、不要外框、不要背景景物。
```

## 2. 负面提示词（单独发一句）

```
避免出现：写实、3D 渲染、照片级、塑料反光、金属高光、荧光色、渐变网格、
浓重投影、背景景物、多个物体、文字、字母、数字、标志、水印、签名、
模糊、细线描边、草稿线、杂乱、透视畸变、物体被裁切。
```

## 3. 出图规格

| 类别 | 生成比例 | 生成尺寸 | 导出尺寸 | 格式 |
|---|---|---|---|---|
| 物品图标 | 1:1 | 1024 × 1024 | **288 × 288**（96dp @3x） | PNG-24 带透明 |
| 生成器 | 1:1 | 1024 × 1024 | **384 × 384**（128dp @3x） | PNG-24 |
| 猫头像 | 1:1 | 1024 × 1024 | **384 × 384** | PNG-24 |
| 房间（前/后） | 9:16 | 1152 × 2048 | **1080 × 1920** | WebP（< 300KB） |
| 章节插画 | 9:16 | 1152 × 2048 | **1080 × 1920** | WebP |
| 启动画面 | 9:16 | 1152 × 2048 | **1080 × 1920** | WebP |
| UI 面板 | — | — | — | **不要用 AI**，用 Figma |

**为什么生成 1024 再缩到 288**：大图缩小自带抗锯齿，边缘比直接出 288 干净得多。

## 4. 后处理五步（每个图标都走一遍）

1. **抠图**：白底转透明。批量用 `rembg`，单个用 remove.bg。
2. **统一描边**：AI 的描边粗细会飘。在 PS / Figma 里加一层 4px 外描边（#3E3226，20% 透明），盖住原描边。
3. **缩放**：1024 → 288，双三次。
4. **检查**：缩到 44dp 看还认不认得出（这是实际显示尺寸）。
5. **命名**：`ic_wood_3.png` 这种，见 11 的命名规范。

## 6. 生成器（7 台，每台 5 级）

基础提示词：

```
{第 1 节风格锁定段}
一个{基础物体}，{等级形容词}；游戏工具图标，比普通物品图标更大、更厚实一点。
```

五级形容词固定用这一套，保证 7 台机器风格一致：

## 10. 不建议用 AI 做的

| 东西 | 原因 | 替代 |
|---|---|---|
| UI 面板 / 按钮 / 9-slice | 圆角描边对内阴影要求极高，AI 每次都不同 | Figma 画，导出 9-slice |
| 字体 | — | 思源宋体 / 思源黑体 |
| 功能小图标（锁、加号） | 太简单，AI 会加戏 | Material Symbols 或手画 |
| 特效序列帧 | 帧间不连贯 | 用代码做粒子，或买素材包 |
| Logo / 招牌文字 | 中文字必错 | 自己排版 |

## 11. 一次完整对话长这样

**第 1 轮**（定风格）：

```
[贴第 1 节风格锁定段]
三块浅松木板叠在一起，用麻绳捆着。
```

**第 2 轮**（确认后锁风格）：

```
很好。从现在开始，所有图都保持和这张完全一样的画风、描边粗细、配色和阴影，
我会一个一个给你物体。
```

**第 3 轮**（下一个物品，带上参考图）：

```
[上传上一张]
同样的画风。一个带盖的小木箱，两侧有绳把手。
```

**第 4 轮**（不满意就微调）：

```
同一个木箱，但盖子改成关着的，不要绳子。其他全部保持不变。
```

## 12. 验收清单

- [ ] 缩到 44dp，还能一眼看出是什么
- [ ] 描边粗细和别的图标一致（±1px）
- [ ] 底色不是纯白（说明有渐变或环境色，要重出）
- [ ] 没有多余投影落到背景上
- [ ] 同链相邻两级，形状明显不同
- [ ] 文件名符合 `ic_{chain}_{level}.png`
- [ ] 透明背景、PNG-24

> 如果一批图风格飘了，不要一张张修——**回到锚点图重开一个对话**，比修补快。

> 中文提示词偶尔会不如英文稳。如果某一张怎么调都不对，只把那一个物体的描述换成英文再试一次，风格锁定段保持中文不动。
