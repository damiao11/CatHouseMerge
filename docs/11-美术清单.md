# 11 · 美术清单

> 规格（色板、字号、描边、动效时长）在 [06 UI 规范](06-UI-UX设计规范.md)，这里只列**要做哪些东西、多少、先做哪个**。
> 用 AI 出图的具体提示词和尺寸见 [12 AI 出图指南](12-AI出图指南.md)。
>
> 总量 **约 190 个资源**（含状态变体），其中必须先做的 **70 个**。两人做，建议按"先占位、后精修"推进。

- 39 个图标放一起要像一套：同一光源、同一描边、同一透视。

## 2. 生成器（7 台 × 5 级 = 35）

| 生成器 | L1 | L2 | L3 | L4 | L5 |
|---|---|---|---|---|---|
| 木工台 | 木箱工作台 | 四条腿木桌 | +台钳、下层隔板 | +工具墙、抽屉 | +竖插的木料架 |
| 铁工台 | 木墩上的铁砧 | +铁箍加固的台面 | +台钳 | +工具墙 | +砂轮和淬火水槽 |
| 缝纫台 | 小木凳 + 针线篮 | 木桌 + 针线筐 | +抽屉 | +挂线架 | +缝纫机 |
| 灯工台 | 小桌 + 灯泡盒 | +灯座 | +工具盘 | +挂灯架 | +整排成品灯 |
| 陶轮 | 木板上的泥团 | +陶轮底座 | +转盘 | +水盆 | +完整拉坯机 |
| 育苗架 | 单层木架 + 花盆 | 双层木架 | +浇水壶 | 三层 + 爬藤 | +带棚架的育苗角 |
| 旧木箱 | 旧木箱 | +铜锁扣 | +内部隔层 | +堆着的旧物 | +阁楼角落的箱堆 |

**原则**：相邻两级的区别必须落在**外轮廓**上（伸出的台钳、竖起的木板、高出的架子）。
只是"台面上多几样小东西"，缩到 132px 是看不出来的。

**省力方案**：只画 **L1 / L3 / L5 三档**（21 张），L2、L4 用同图 + 色调差 + 尺寸差区分。工期砍 40%，但去掉角标后同级识别会变弱，只能靠"拖起时同级高亮"补。

画布 384×384 px（= 128dp @3x），但**显示仍只占 44dp 一格**；要靠造型区分，不能靠尺寸。

## 3. 房间前后对比（8 间 × 2 + 局部贴图）

整图 1080×1920 竖版 WebP（< 300KB），**用作建造界面（第 3 屏，独立于棋盘）的全屏背景**：顶部约 10% 会被顶栏压住、底部约 20% 要留给房间名与建造按钮，重要细节放在中间 60%，上下边缘只画氛围。

| 房间 | 修复前 | 修复后 | 局部变化（2 个） |
|---|---|---|---|
| 门廊 | 破门、落叶、歪门牌 | 修好的门、门垫、门牌挂正 | 门板、门垫 |
| 玄关 | 空、积灰、鞋散落 | 鞋柜、挂钩、镜子 | 鞋柜、挂钩 |
| 客厅 | 家具蒙白布 | 沙发、地毯、书架 | 沙发、地毯 |
| 卧室 | 旧床、破窗 | 床、窗帘、吊灯 | 窗帘、床品 |
| 厨房 | 锈灶台、空柜 | 瓷砖、餐具、吊灯 | 灶台、瓷砖 |
| 院子 | 杂草、倒下的花盆 | 花坛、石凳、晾衣绳 | 花坛、石凳 |
| 阁楼 | 堆满纸箱、灰尘 | 清出空地、天窗、旧木箱 | 天窗、木箱 |
| 全屋 | 夜景、黑窗 | 全屋亮灯 | 窗光、门牌 |

**为什么拆两层**：整图只做 2 张（前/后），三个建造步骤里前两步用"局部贴图叠加"表现，第三部换整图。这样每间房只需要 2 张大图 + 2 张透明小贴图。

## 8. 功能小图标（约 12）

锁、加号、关闭、返回、设置、音量、勾、箭头（上下左右）、感叹号、**爪印**（剧情单角标）。

另加 **7 个链条形状标识**（圆 / 方 / 三角 / 水滴 / 叶 / 星 / 沙漏），印在物品底托上，帮助色盲玩家分辨链。

## 10. 命名规范

```
ic_{chain}_{level}.png        ic_wood_3.png
gen_{chain}_{level}.png       gen_wood_2.png
room_{room}_{before|after}.png  room_porch_before.png
room_{room}_part{n}.png       room_porch_part1.png
ui_{name}_{state}.png         ui_btn_primary_pressed.png
cat_{id}_{face}.png           cat_orange_happy.png
fx_{name}.png                 fx_merge_spark.png
```

全小写、下划线、不用中文文件名（打包和跨平台都省事）。

## 11. 生产顺序（重要）

| 阶段 | 做什么 | 目的 |
|---|---|---|
| 第 1 步 | **3 张定调图**：主界面、一间房的前后、一只猫 | 定风格，避免后面全部返工 |
| 第 2 步 | UI 底板 + 底栏图标 + 金币/体力图标 | 骨架先立起来 |
| 第 3 步 | 7 条链的 **L1 / L3 / L5**（21 张） | 够跑通全部玩法 |
| 第 4 步 | 8 间房的前后整图（16 张） | 建造系统的门面 |
| 第 5 步 | 生成器 5 档 + 补齐物品 L2/L4 | 精修 |
| 第 6 步 | 猫的表情、插画、特效 | 加分 |

## 12. 最小可玩集（70 个）

如果时间不够，砍到这些也能完整跑通：

- 物品 21（每条链 L1/L3/L5，其余用同图 + 色调/尺寸差）
- 生成器 7（单张 + 尺寸差）
- 房间 16（只要前后，不要局部贴图）
- UI 12（背景、顶栏、订单卡、棋盘格、底栏、4 个图标、主按钮、弹窗、对话框）
- 猫 12（6 头像 + 6 剪影）
- 插画 2（启动 + 结局）

## 13. 明确不做

- 3D、粒子系统、着色器
- 全屏立绘、Live2D、语音
- 多语言版本的图（只做中文）
- 平板/横屏专用图
- 表情包式的夸张变形（风格是"温暖手账"，不是"搞笑")
