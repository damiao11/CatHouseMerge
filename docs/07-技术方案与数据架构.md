### 三条铁律（沿用）

- 数据（JSON）与渲染分离，**改数值不改代码**。
- 引擎层（合成、订单、经济）是纯 Kotlin，**不 import `android.*`**，能 JUnit 直接测。
- 存档是一棵状态树，序列化成一个 JSON，**不用数据库**，方便打印和调试。

### 7.3.3 手势与拖拽（唯一的自研难点）

| 行为 | 实现要点 |
|---|---|
| **点生成器** | `detectTapGestures { onTap }` → 调 `GeneratorEngine.spawn(cell)`，扣 1 体力 |
| **点物品** | 只把底部信息条切到该物品，不移动 |
| **拖起** | `detectDragGestures` 的 `onDragStart`：位移 > **8dp** 才算拖拽，否则按点击处理 |
| **跟手** | 被拖物品画在 **overlay 层**（`Box` 顶层），中心吸附手指，`zIndex` 最大 |
| **同级高亮** | 拖起时遍历棋盘，同链同级的格子加 2dp `Success` 描边 + 呼吸 |
| **落点判定** | 松手坐标换算：`col = (x / 44.dp).toInt()`、`row = (y / 44.dp).toInt()`，越界视为无效 |
| **合并** | 目标格空 → 移动；同链同级 → 合并并 +1 级；否则 → 150ms 回弹 |
| **生成器不可合并进物品** | 生成器只和同链同级生成器合并（升 1 级） |

> 判定阈值 8dp 的作用：手指点击时会有 2–5dp 抖动，不做阈值会把点击误判成拖拽。

### 7.3.4 导航与状态

- **单 Activity**，`MainActivity` 里一个 `NavHost`：

```
board            主界面（棋盘）
build/{roomId}   建造界面（独立整屏）
warehouse        仓库
almanac          图鉴
```

- **对话不是路由**：它是覆盖在任意屏之上的 `Dialog/Box` 层，退出后回到原来的屏。
- `GameViewModel` 持有唯一的 `StateFlow<GameState>`；所有 Screen 只读状态、只发事件：

```kotlin
sealed interface GameEvent {
    data class TapGenerator(val cell: Int) : GameEvent
    data class DropItem(val from: Int, val to: Int) : GameEvent
    data class DeliverOrder(val orderId: String) : GameEvent

```

- **不要在 Composable 里写规则**：UI 只发事件，状态变化全部由 ViewModel → 引擎完成。

```kotlin
data class GeneratorDef(
    val id: String,
    val chainId: String,
    val maxLevel: Int,
    // 每级的产出权重，index = 物品等级-1
    val output: List<List<Float>>  // 例：[[1.0],[0.6,0.4],[0.2,0.55,0.25]]

data class BoardState(
    val cols: Int = 7,
    val rows: Int = 9,
    val cells: List<Cell>      // size = cols * rows = 63

    fun index(x: Int, y: Int) = y * cols + x
}

@Serializable
data class Cell(
    val locked: Boolean = false,
    val item: ItemInstance? = null,
    val generatorId: String? = null   // 生成器占格时非空，与 item 互斥

@Serializable
data class ItemInstance(
    val uid: Long,
    val defId: String,
    val level: Int
```

**引擎函数必须是纯函数**：

```kotlin
fun merge(board: BoardState, from: Int, to: Int): MergeResult {
    val a = board.cells[from].item ?: return MergeResult.Invalid
    val b = board.cells[to].item ?: return MergeResult.Invalid
    if (a.defId.substringBeforeLast('_') != b.defId.substringBeforeLast('_')) return MergeResult.Invalid
    if (a.level != b.level) return MergeResult.Invalid
    if (a.level >= maxLevel) return MergeResult.Invalid
    return MergeResult.Success(newItem = a.level + 1, from = from, to = to)
}
```

> 纯函数 = 可以写 200 个单元测试 = 合成规则不会在答辩前夜崩。

## 7.6 棋盘渲染

**推荐：Canvas 画底 + 组合式物品。**

```
Box(Modifier.fillMaxSize()) {
    Canvas { /* 画格子、选中态、遮罩：静态，只画一次 */ }
    items.forEach { item ->
        ItemCell(item, Modifier.offset { cellOffset(item.cell) })
    }
    DragOverlay()   // 拖拽中的那一张，画在最上层
}
```

- **不做** 63 个 `pointerInput`：会在棋盘 `Box` 上装**一个**手势检测，用坐标算出格子索引。少 63 个手势节点，手感更稳。
- 拖拽位移用 `mutableStateOf(Offset)`，**不要放 ViewModel**——否则每帧重组整个页面。
- 合成动画用 `Animatable`，别用 `animateFloatAsState` 做序列（打断会乱）。

```kotlin
fun hitTest(pos: Offset): Int? {
    val x = ((pos.x - padding) / (cellSize + gap)).toInt()
    val y = ((pos.y - padding) / (cellSize + gap)).toInt()
    if (x !in 0 until cols || y !in 0 until rows) return null
    return y * cols + x
}
```

## 7.7 存档

```kotlin
@Serializable
data class SaveData(
    val version: Int = 1,
    val day: Int = 1,
    val coins: Int = 0,
    val energy: Int = 150,
    val energyAt: Long = 0,          // 上次结算时间戳
    val board: BoardState,
    val generators: List<GeneratorState> = emptyList(),
    val warehouse: WarehouseState = WarehouseState(),
    val bubble: List<String> = emptyList(),          // 气泡里还没放置的生成器 id
    val ordersDoneToday: Set<String> = emptySet(),   // 当天已交付的订单 id
    val buildDone: List<String> = emptyList(),
    val seenDialogue: Set<String> = emptySet(),
    val cats: Set<String> = emptySet(),
    val wallColor: String? = null
)
```

- 自动存档：每次状态变更后 **debounce 500ms** 写文件。
- **原子写**：先写 `save.json.tmp`，再 `rename`，防止写一半断电损坏。
- 版本号用于迁移；读失败就备份 `save_broken.json` 并开新档（别让玩家卡在崩溃里）。
- 能量恢复**不用后台服务**：启动/回前台时用 `now - energyAt` 算，`min(上限, energy + elapsed/60)`。
