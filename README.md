# 猫屋合合 · Cat House Merge

> 外婆留下一栋旧屋、一条老街，和六只不肯走的猫。
> 玩家用「合成」把房子一间间修回来，也把一段被遗忘的日子拼回来。

| 项目 | 内容 |
|---|---|
| 课程 | 移动应用开发（期末作业） |
| 形态 | Android 竖屏 · 单机 · 合成 + 建造 + 轻叙事 |
| 参考 | 《肥鹅美食街》《四季合合》《Merge Mansion》 |

## 结论速览

1. **主题定「家居修缮」**：合成的是材料 → 家具成品，不是锤子抹布。
2. **24 天 = 4 章 × 2 间房 × 3 天**：每 3 天一间房、一条主链，玩家永远在学新东西，但只需记 6 个等级。
3. **7 个生成器可升级**：两个同级合成一级，等级永久继承，产出按概率分布（1.0 → 4.0 倍），**5、6 级永不直出**。
4. **生成器占棋盘 1 格**，新工具先进**订单行最前面的气泡**（和卡片同高），取完即收起。
5. **订单每天固定 4–6 条，全部显示，不可刷新**；建造纯花金币，不消耗物品。
6. **不做垃圾**：板面压力只来自生成器和自己合成的物品。
7. **前 3 天是教学**（门廊），占全程 12.5%。
8. **体力 150 / 2 分钟一点**：每天实际用 0.29–0.96 管。
9. **难度 5 个旋钮 + 24 天全表**，全部数据驱动，配 Debug 面板现场调。
10. **UI 先写规范再写界面**：色值、字号、间距、动效时长全部定死。
11. **猫是订单发布者**，一套内容两用；六只猫对应六段关系。
12. **技术栈已锁定 Kotlin + Jetpack Compose**：设计全部数据驱动，实现规格见 07。
