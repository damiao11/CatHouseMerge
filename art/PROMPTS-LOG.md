# 出图提示词记录（定稿）

> 这是**实际出图成功、已经定稿**的提示词，可以直接复制使用。
> `docs/data/prompts.txt` 是第一版通用库（没迭代过），两者不要混用。

## 通用工作流

1. 新开一个对话，上传 `art/items/wood/ic_wood_3.png` 当风格参考
2. 发一句：`保持和参考图完全一样的画风、描边粗细、纸纹和阴影，阴影要和参考图一样淡、一样偏暖。`
3. 把下面对应条目的**整段**贴进去

## 迭代出来的五条规则

| 踩过的坑 | 解法 |
|---|---|
| 金属被画成 3D 反光 | `表面是哑光的，像纸板剪出来再上色的贴纸` |
| 细长物体缩略后变一条线 | `加粗` + `倾斜 15 度` |
| 灰色发冷、和暖色木工不搭 | `偏暖的灰，带一点米色，不要冷蓝灰` |
| 阴影发灰发硬 | `暖米色、边缘柔和、小而淡` |
| 参考图是木头，别的东西被染成木色 | `参考图只用来对齐画风，不要照抄它的木头颜色` |

**B. 修色用**（首版夹了绿色和橙色木片，用这句修掉；只在上一步出图后接着发）：


> **注意**：A 和 B 要分开存。把 B 混进 A 里，AI 会以为你要改一张已有图。

## 七台生成器的统一规律（写新台子时照这个来）

1. **每级上传上一级的图**，只加东西，不换主体。
2. **相邻两级的区别必须落在轮廓或大色块上**：伸出的台钳、竖起的木板、立起的盖子、并排的箱子。
   只"多几样小东西"，缩到 132px 是看不见的。
3. **每一级只让一个地方变**，否则画面会越堆越糊。
4. **给结构一个高度参照**（"高过那盆植物的叶子"），比"高一点"有效。
5. **"不要 X"常常无效甚至反效果**，改用数量限制（"一共四件"）或位置限定（"搬离木板"）。

> 房间图用在**建造界面（第 3 屏，独立于棋盘）**，全屏背景，9:16。
> 核心做法：**先做"装修前"，再上传它做"装修后"**，只改状态、不改机位。
